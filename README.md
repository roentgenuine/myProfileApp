# myProfileApp

A simple React Native profile page built with core components: `View`, `Text`, `Image`, and `StyleSheet`.

## Features
- Welcome header (Text)
- Profile picture, name, and introduction (Image + Text)
- List of interests/hobbies (Text)
- Styling done via `StyleSheet.create()` — background color, text color, font size/weight, margin/padding, image sizing, borders, and border radius.

## Run locally (Expo)
```
npm install
npx expo start
```
Scan the QR code with the Expo Go app on your phone, or press `w` to run in a browser.
